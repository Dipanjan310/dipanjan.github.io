# Dipanjan Bera — Academic Website

A responsive academic website with About, Experience, Research, and Others sections. Includes a light/dark theme toggle, scroll-aware navigation underline, owl emoji favicon, social profile links, advisor link, and downloadable CV.

## Files
- `index.html` — content and navigation
- `style.css` — reference-inspired styling and light/dark themes
- `script.js` — theme toggle and active section underline
- `Dipanjan_Bera_CV.pdf` — downloadable CV

## Publish/update
1. Review the CV PDF before publishing; it includes contact information from the uploaded resume.
2. Sign in at https://github.com/ and open your existing `YOUR-USERNAME.github.io` repository.
3. Upload these files into the repository root, replacing the corresponding older files.
4. Commit the changes.
5. Wait for GitHub Pages to deploy, then refresh your site with Ctrl+F5.

The academic profile links and advisor website are already set based on the URLs provided. The profile image is intentionally a DB initials placeholder.
